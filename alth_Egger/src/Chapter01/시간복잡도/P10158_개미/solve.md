     개미의 이동 분석

문제 분석

개미의 이동을 X축과 Y축으로 나누어 생각해보면, 다음과 같은 사실을 알 수 있습니다:

X축 이동

개미는 2W의 주기로 움직입니다.

개미가 이동하는 방향까지 고려했을 때, 12시간이 지나면 개미는 다시 오른쪽으로 이동하는 x=4 위치에 도달합니다.

Y축 이동

Y축 역시 2H의 주기로 움직입니다.

주기의 활용

개미가 2W와 2H의 주기로 반복적으로 움직이므로, 특정 시간 t에서 개미의 위치를 계산할 때 모듈러 연산을 활용할 수 있습니다. 이를 통해 개미의 위치를 효율적으로 계산할 수 있습니다:

주기를 활용하면, 시간 t에 대해 반복적인 계산 없이 간단히 위치를 구할 수 있습니다.

풀이 과정

핵심 코드 분석

int timeX = t % (2 * w);
int deltax = 1;
int currentX = x;
while (timeX-- > 0) {
if (currentX == w) deltax = -1;
else if (currentX == 0) deltax = 1;
currentX += deltax;
}

1. 변수 설명

timeX:

남은 이동 시간을 계산하기 위해 t % (2 * w)로 초기화합니다.

이는 X축 이동의 주기를 반영한 값입니다.

deltax:

개미의 이동 방향을 나타냅니다.

1: 오른쪽으로 이동.

-1: 왼쪽으로 이동.

currentX:

개미의 현재 X좌표를 나타냅니다.

2. 반복문의 역할

이동 방향 결정:

currentX == w: 오른쪽 끝에 도달했으므로 방향을 왼쪽으로 변경 (deltax = -1).

currentX == 0: 왼쪽 끝에 도달했으므로 방향을 오른쪽으로 변경 (deltax = 1).

위치 업데이트:

currentX를 현재 방향 (deltax)에 따라 한 칸씩 이동합니다.

3. Y축 계산

Y축도 동일한 방식으로 계산됩니다. 주기와 방향을 활용하여 위치를 구합니다.

결론

개미는 2W와 2H의 주기로 움직이므로, 특정 시간 t에서 위치를 계산할 때 모듈러 연산을 적용할 수 있습니다.

핵심 코드 요약

t % (2 * w)와 t % (2 * h)를 통해 주기를 반영.

currentX와 currentY를 방향에 따라 업데이트하여 최종 위치를 계산.

좌표 출력
